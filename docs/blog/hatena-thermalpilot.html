１. ThermalPilot とは 🌡️✨

メニューバーに常駐して, Mac の温度を ｢快適 / ほんのり / アツい / 危険｣ の 4 段階で表示する, 無料・オープンソース (MIT) のアプリです 🍵

Apple Silicon (M1〜M5) と Intel の両方に対応しており, macOS 14 Sonoma 以降で動きます

いちばんのこだわりは, ただ温度を見せるだけではなく ｢熱の犯人候補｣ と ｢冷却アクション｣ まで出すところです 🔎

２. できること 📋✨

３. Mac を冷やすために ｢本当に効く｣ 3 つのこと 🧊✨

作ってみて分かったのですが, Mac の温度は, macOS 自身 (thermalmonitord という常駐プログラム) が, ほぼ完璧に自動管理しています

なので, アプリ側でできることは, 実は 3 つしかありません

  1. 熱源を止める・・・ 暴走しているアプリを見つけて, 閉じる。これがいちばん効きます
  2. 電力を絞る・・・ 低電力モードを ON にする。数分で 5〜10 ℃ 下がることが多いです
  3. ファンを先回りで回す・・・ 静音優先の macOS より早めに回して, ピークを抑える

ThermalPilot は, 1 と 2 を標準機能にして, 3 は ｢やりたい人だけ｣ のオプトインにしました

というのも, Apple Silicon では, ファンを手動で回しても macOS が数秒で制御を取り返してしまい, 設定を間違えるとハードウェアを傷める可能性もあるためです ⚠️

４. 作り方 (Claude Code にお任せしました) 🤖✨

今回の流れは, こんな感じでした

  1. Claude Code に ｢Mac の温度を管理するアプリを作りたい。まず GitHub のリポジトリから Skills 等をリサーチして｣ とお願い
  2. 先行プロジェクト (macmon, FanBar, smctl, agoodkind/macos-smc-fan など) と, Apple 開発用の Claude Skills (rshankras/claude-code-apple-skills) を調査してもらう
  3. 調査結果をもとに, Swift Package として実装。ユニットテストも 15 件
  4. Mac で swift build と swift test を通して, 実機のセンサー名を見ながら表示を調整
  5. GitHub に公開

調査で分かった, ちょっと面白いポイントです 🔎

  • Apple Silicon の温度は SMC ではなく, IOHID のセンサーハブ という非公開 API から読む (macmon や Stats と同じ方式)
  • 2026 年は, Swift 製のファン制御アプリが 10 本以上 乱立していて, ｢ファンを回す｣ だけでは差がつかない
  • Apple Silicon でファンを手動制御するには, Ftst という診断フラグでロックを外す必要がある (agoodkind さんの研究)

調査レポートはリポジトリの docs/RESEARCH.md に, Claude Code 用の Skill は .claude/skills/ に入れてあります 📚

５. 導入手順 (3 ステップ) 🛠️✨

Xcode 16 以降が入っていれば, ターミナルで 3 つ実行するだけです

手順 1：クローン

git clone https://github.com/tokoinx/ThermalPilot.git && cd ThermalPilot

手順 2：ビルド (アプリと CLI を dist/ に作ります)

bash scripts/build-app.sh

手順 3：起動

open dist/ThermalPilot.app

メニューバー右上に, 温度計のアイコンが出れば成功です ✨ 常用する場合は /Applications にコピーしてください

zip で入手して killed と出る隔離属性が原因です。xattr -dr com.apple.quarantine ThermalPilot を 1 度実行

７. 注意点 ⚠️

  • 温度の読み取りに 非公開 API を使っているため, Mac App Store では配布できません (自分でビルドして使う形です)
  • ファン制御 (sudo thermalctl) は 自己責任 でお願いします。ハードウェアが報告する範囲内に収める安全策は入れていますが, 無理に回すのはおすすめしません
  • MacBook Air などのファンレス機では, ファン欄は出ません (温度と犯人候補は使えます)
